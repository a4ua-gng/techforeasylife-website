SK GROUP X — DEALERSHIP WEBSITE

The public website is static and the HTML files can be hosted directly.
Each of the five dealership pages has a first-visit contact panel. It
shows that branch's phone number, directions, and a group email link.
The contact button can reopen it after dismissal. Group enquiries
compose a draft in the visitor's email app, where they review and send.

To edit dealership details or photographs, update source/content.json
then run: python3 source/build.py
The builder checks that a dealership can only display its own photos.
Keep the verified branch phone, address and map query together.
