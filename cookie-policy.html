The current website build

The public website code sets no advertising or analytics cookies. It includes no Meta Pixel, Google Analytics, Tag Manager or session replay. It does not embed YouTube players, Instagram feeds or maps. Fonts and photographs are served with the site.

Because this version includes no optional visitor tracking or embedded media, it does not show an “Accept all cookies” banner. Necessary hosting and security behaviour must still be checked on the final production domain. If optional tracking or embeds are added later, review applicable consent requirements and prevent them from loading until any required consent is given.

Browser storage and functional controls

FeatureStorage and purpose
Enquiry formNo site storage. Fields remain in page memory. Your email app controls its own drafts.
SafeFlight demonstrationA session marker records that this browser tab completed the demonstration. It contains no name or email and expires with the page session.
Skyway gameScore remains in page memory and is reset when the page is reopened.
Admin design previewOnly when Save demo is selected, browser local storage keeps content draft settings. Reset demo removes this preview draft. No visitor enquiry data is stored.
Space motion preferenceOnly when you use the motion button, session storage remembers whether site animations and smooth scrolling are paused. This is a functional preference with no personal details or advertising use.
Intro animationA session-only flag remembers that the short TEL loading intro has already been shown in this tab. It contains no personal details and prevents the animation repeating on every page.

Your controls

Your browser settings can clear site storage or block it. Blocking storage may stop the admin demo from retaining drafts. You can use the public site without saving an admin draft. Device autofill and email history are controlled by your browser or email provider.

External services receive a request only when you follow their link or deliberately load the optional weather lookup. See the Privacy Policy for details. Questions can be sent to techforeasylife.operations@gmail.com.
